Files you pick are uploaded to the PC over Wi-Fi. Keep this screen awake and the tab in the foreground while transferring — on iOS, locking the screen or backgrounding the tab pauses the upload.

    First time on this iPhone?

    lan-drop serves HTTPS with its own certificate authority, so Safari shows a warning until you trust it. One-time setup:

    1. Download the CA certificate
    2. Settings → Profile Downloaded → Install
    3. Settings → General → About → Certificate Trust Settings → enable full trust for "lan-drop local CA"
    4. Reopen this page — the warning is gone
