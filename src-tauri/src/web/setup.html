lan·drop first-time setup

Install lan-drop's certificate authority once, then the app opens warning-free from the QR code.

1. Download CA certificate
  1. Tap Allow if Safari asks to download
  2. Settings → General → VPN & Device Management (or "Profile Downloaded") → install the "lan-drop local CA" profile
  3. Settings → General → About → Certificate Trust Settings → enable full trust for lan-drop local CA
  4. Scan the QR code on the PC — the page opens with no warning

This plain-HTTP setup page exists only because the certificate cannot be fetched over HTTPS before it is trusted. It serves nothing else.
